# ملاحظات فحص الدعوات الخاصة

## فحص محلي أولي

في 3 سبتمبر 2026، فُتح مسار `#register` محليًا بعد تعديل الواجهة. ظهرت صفحة «التسجيل بدعوة خاصة» بدل نموذج إنشاء حساب مفتوح، وفيها توضيح أن التاجر يحدد كلمة مروره من رابط الدعوة، مع رابط تسجيل الدخول والعودة للموقع. لم يُنشأ أي حساب أو بيانات اختبار أثناء الفحص.

## قيد معروف قبل المعاينة المتصلة

تعديل `firestore.rules` للدعوات مكتوب محليًا ومعتمد من المالك، لكن لم يُنشر بعد إلى مشروع Firebase لأن جلسة دخول المالك غير متاحة في المتصفح. لذلك لا يصح اعتبار منع التسجيل المفتوح مفروضًا على مشروع Firebase حتى تطبيق القواعد هناك.

## فحص واجهة الفشل والدخول

فُتح رابط دعوة غير صالح محليًا، فظهر تنبيه «رابط الدعوة غير متاح» ولم تُفتح لوحة تاجر. كذلك فُحصت صفحة تسجيل الدخول؛ ظلت حقول الدخول واستعادة كلمة المرور موجودة، وظهرت ملاحظة نصية يجب تعديلها لتوضح أن إنشاء الحساب يتم بالدعوة وليس بالتسجيل المفتوح.

## فحص المسار العام

فُتحت الصفحة الرئيسية محليًا، وبقيت الصفحة العامة تعرض بصورة صحيحة. ظهر أن أزرار الدعوة في الصفحة الرئيسية ما زالت تستخدم نص «أنشئ متجرك» وتتجه إلى `#register`؛ يلزم استبدال النص بتوجيه صريح لطلب الدعوة الخاصة قبل رفع أي معاينة.
