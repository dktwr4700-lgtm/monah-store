# نموذج الاشتراك المعتمد لمُونَة

هذا النموذج يغيّر ما يظهر للتاجر في قائمة الاشتراك فقط. لا يوجد دفع أو تحصيل أو تجديد تلقائي مفعّل الآن.

| العنصر | السعر الشهري | الحالة |
|---|---:|---|
| متجر مُونَة الأساسي | 3 ر.ع | متاح الآن كتوضيح اشتراك. |
| البيع الرقمي | 2 ر.ع | يتفعل بعد ربط الدفع. |
| زيادة المبيعات | 1 ر.ع | يتفعل بعد ربط الدفع. |
| إدارة المبيعات | 1 ر.ع | يتفعل بعد ربط الدفع. |
| حماية إضافية | 0.5 ر.ع | تتفعل بعد ربط الدفع. |
| أدوات الذكاء | 1 ر.ع | متاحة الآن: وصف المنتج ونص الإعلان كمسودات. |
| دومين خاص | 1 ر.ع | يحتاج دومينًا حقيقيًا واختبار ربط قبل تفعيله. |

المجموع عند اختيار كل الإضافات هو 9.5 ر.ع شهريًا. عند تفعيل الدفع لاحقًا، يدفع التاجر المتجر الأساسي مع الإضافات التي يختارها. وإذا أضاف ميزة وسط الشهر، يدفع سعر الإضافة كاملًا وقت إضافتها ثم تدخل ضمن تجديده القادم؛ لا يوجد حساب فرق الأيام.
