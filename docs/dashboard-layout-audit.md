# مراجعة ترتيب صفحة التاجر

## المشكلة الحالية

تبويب المنتجات يجمع نموذج إضافة المنتج وقائمة المنتجات وروابط التتبع وحزم المنتجات في صفحة طويلة واحدة. تظهر حقول كثيرة دفعة واحدة في الجوال، فيصعب على التاجر معرفة أين يبدأ أو الوصول بسرعة للأداة التي يريدها.

## الترتيب المقترح

يظهر أولًا عنوان بسيط وزر واضح لإضافة منتج. يبقى نموذج الإضافة مغلقًا حتى يختار التاجر فتحه. تظهر قائمة المنتجات بعدها مباشرة لأنها الأكثر استخدامًا. تتحول روابط التتبع وحزم المنتجات إلى أقسام قابلة للفتح، فيظهر عنوان كل أداة وحالتها أولًا، ولا تظهر الحقول إلا عند فتح القسم.

## ما لن يتغير

لا تتغير طريقة حفظ أو نشر المنتج، أو روابط التتبع، أو الحزم، أو أدوات الذكاء. التعديل يقتصر على ترتيب واجهة التاجر وتحسين قراءتها على الجوال.
